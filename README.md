# Admin Dashboard

A clean and responsive **Admin Dashboard UI** built using **HTML, CSS, and JavaScript**.  
This project provides a basic admin panel layout with a sidebar, header, main content area, and a dark mode toggle.

---

## ✨ Features

- Simple and clean admin UI
- Sidebar navigation (Home, Users, Settings)
- Top header with dashboard title
- Dark Mode toggle
- Main content area for reports, tables, or charts
- Responsive design
- Beginner-friendly and easy to customize

---

## 🛠 Technologies Used

- HTML5  
- CSS3  
- JavaScript  

No external libraries or frameworks are used.

---

## 🚀 Usage

- Open the `index.html` file in any modern web browser  
- Use the sidebar to navigate between sections  
- Toggle Dark Mode using the checkbox in the top-right corner  
- Replace the main content section with your own charts, tables, or data

---

## 🎯 Purpose

This project is ideal for:
- Learning basic frontend dashboard layouts
- College mini-projects
- Practice for admin panel UI design
- Portfolio or GitHub showcase
